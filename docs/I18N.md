# Internationalization (I18N) Guide

Ushbu hujjat Mebel Salon loyihasida ko'p tillilikni (i18n) qanday amalga oshirish va boshqarish haqida ma'lumot beradi. Loyiha [next-intl](https://next-intl-docs.vercel.app/) kutubxonasidan foydalanadi.

## Supported Languages

Loyiha quyidagi tillarni qo'llab-quvvatlaydi:
- **UZ** - O'zbek tili (Birlamchi/Default)
- **RU** - Rus tili
- **EN** - Ingliz tili

## next-intl Setup and Configuration

`next-intl` App Router bilan integratsiya qilingan. Barcha sahifalar `[locale]` dinamik papkasi ichida joylashadi (`app/[locale]/page.tsx`).

Asosiy konfiguratsiya fayllari:
- `i18n.ts` - next-intl so'rovini qabul qiluvchi va mos tilni yuklovchi fayl.
- `middleware.ts` - foydalanuvchining tilini aniqlaydigan va mos URL'ga yo'naltiruvchi middleware.

## Message Files Structure

Tarjima fayllari JSON formatida saqlanadi va loyiha ildizidagi `messages/` papkasida joylashadi:

```text
messages/
├── uz.json
├── ru.json
└── en.json
```

## Namespace Organization

Tarjimalar komponentlar va qismlarga qarab guruhlanadi (namespaces):

```json
{

```

## Adding Translations for New Components

Yangi komponent yaratganda:
1. Kerakli matnlarni `messages/uz.json`, `ru.json`, `en.json` fayllarida tegishli namespace ichiga qo'shing.
2. Komponent ichida `useTranslations` (Client) yoki `getTranslations` (Server) hook'laridan foydalaning.

### Server Components
```tsx
import { getTranslations } from 'next-intl/server';

export default async function CatalogPage() {
  const t = await getTranslations('catalog');
  
  return <h1>{t('title')}</h1>;
}
```

### Client Components
```tsx
'use client';
import { useTranslations } from 'next-intl';

export default function SubmitButton() {
  const t = useTranslations('forms');
  
  return <button>{t('submit')}</button>;
}
```

## Dynamic Content Translation

Ma'lumotlar bazasidagi dinamik kontent (masalan, toifalar, kolleksiyalar va mebellar nomlari) uchta tilda saqlanadi. 

Prisma model misoli:
```prisma
model Product {
  id          String   @id @default(uuid())
  titleUz     String
  titleRu     String
  titleEn     String
  // boshqa maydonlar...
}
```

Ma'lumotni frontendda ko'rsatishda joriy tilga mos maydon tanlanadi:
```tsx
// lib/i18n-helpers.ts da type-safe helper yaratiladi:
type Locale = 'uz' | 'ru' | 'en';

interface LocalizedTitle {
  titleUz: string;
  titleRu: string;
  titleEn: string;
}

interface LocalizedName {
  nameUz: string;
  nameRu: string;
  nameEn: string;
}

export function getLocalizedTitle(item: LocalizedTitle, locale: Locale): string {
  const map: Record<Locale, string> = {
    uz: item.titleUz,
    ru: item.titleRu,
    en: item.titleEn,
  };
  return map[locale] || item.titleUz; // UZ fallback
}

export function getLocalizedName(item: LocalizedName, locale: Locale): string {
  const map: Record<Locale, string> = {
    uz: item.nameUz,
    ru: item.nameRu,
    en: item.nameEn,
  };
  return map[locale] || item.nameUz; // UZ fallback
}

// Komponentda ishlatish:
import { getLocalizedTitle } from '@/lib/i18n-helpers';
const title = getLocalizedTitle(product, locale as Locale);
```

## Language Switcher Component

Til o'zgartirish tugmasi foydalanuvchiga tilni almashtirish imkonini beradi. U odatda joriy URL'ni saqlab qolgan holda URL prefiksini o'zgartiradi (`/uz/catalog` -> `/ru/catalog`). Bu `next-intl` ning `useRouter` va `usePathname` orqali amalga oshiriladi.

## URL Routing with Locale Prefix

Ilovaning URL tuzilishi har doim til prefiksiga ega bo'ladi:
- `/uz` - Bosh sahifa (O'zbek tilida)
- `/ru/catalog` - Katalog (Rus tilida)
- `/en/contacts` - Kontaktlar (Ingliz tilida)

Foydalanuvchi til prefiksisiz (masalan, `/catalog`) kirishga harakat qilsa, Middleware uni birlamchi tilga (`/uz/catalog`) yo'naltiradi.

## Fallback Strategy

Agar biror matn RU yoki EN tarjimasida mavjud bo'lmasa, `next-intl` da `fallback` til (UZ) o'rnatilgan bo'lishi mumkin yoki shunchaki kalit so'zni o'zini chiqaradi. Xatolarni oldini olish uchun har doim barcha tillarda tarjimalar to'liq ekanligini tekshirish tavsiya etiladi.

## Translation Completeness Check

Barcha tillarda tarjimalar to'liq ekanligini tekshirish uchun CI/CD pipeline da quyidagi script ishlatiladi:

```bash
# scripts/check-translations.ts
import uz from '../messages/uz.json';
import ru from '../messages/ru.json';
import en from '../messages/en.json';

function getKeys(obj: Record<string, unknown>, prefix = ''): string[] {
  return Object.entries(obj).flatMap(([key, val]) =>
    typeof val === 'object' && val !== null
      ? getKeys(val as Record<string, unknown>, `${prefix}${key}.`)
      : [`${prefix}${key}`]
  );
}

const uzKeys = getKeys(uz);
const ruKeys = getKeys(ru);
const enKeys = getKeys(en);

const missingRu = uzKeys.filter(k => !ruKeys.includes(k));
const missingEn = uzKeys.filter(k => !enKeys.includes(k));

if (missingRu.length || missingEn.length) {
  console.error('Missing translations:', { missingRu, missingEn });
  process.exit(1);
}
```

Bu script `npm run check:i18n` buyrug'i orqali ishga tushiriladi va build jarayoniga qo'shiladi.

## Date and Number Formatting

`next-intl` sana va raqamlarni formatlash uchun o'rnatilgan vositalarni taqdim etadi. O'zbek tili uchun o'ziga xos valyuta va sana formatlarini `i18n.ts` faylida sozlash mumkin.

## RTL Considerations

O'zbek, Rus va Ingliz tillari chapdan o'ngga (LTR - Left To Right) yozilganligi sababli, o'ngdan chapga (RTL - Right To Left) yozish bo'yicha maxsus sozlamalar hozircha talab qilinmaydi. Agar kelajakda Arab yoki Fors tillari qo'shilsa, HTML `dir="rtl"` attributi va Tailwind ning RTL plaginlari orqali boshqariladi.

## How to Add a New Language

1. `next-intl` konfiguratsiyasida `locales` massiviga yangi til kodini qo'shing.
2. `messages/` papkasida yangi til uchun JSON fayl yarating (masalan, `tr.json`).
3. Ma'lumotlar bazasida (Prisma) har bir ko'p tilli modelga tegishli maydonlarni qo'shing (masalan, `titleTr`, `descriptionTr`).
4. Barcha tillarni tanlash komponentlarini yangilang.
